# 倾国
展现了游郭深处绝顶花魁与夺命刺客的双重致命美学。她身着穷极奢华的重绛红、群青与金箔牡丹重锦打挂，高耸发髻满插摇曳的玳瑁步摇与金簪。画面中花魁凌空反向飞旋跃杀，素手双持金骨铁折扇在胸前交叉斩出破空月牙墨刃，另一广袖中暗藏淬毒银匕；身后满头黑发与华服狂暴炸裂为巨幅水墨雷云与漫天散落的墨蝶樱瓣，凤眼含煞、嘴角含笑，美艳绝伦亦凶险至极。

# 雷霆
佛门武僧化身金刚力士、以雷霆万钧之势扫荡妖氛的狂暴瞬间。铜铸般的半裸胸肌青筋贲张，深赭色粗布袈裟斜裹，胸前悬挂沉重的大粒黑檀念珠。狂僧凌空暴喝飞身下砸，双臂合握千钧八角黑铁金刚棒从右上角斜贯左下角，刚猛重力将脚下虚空与和纸背景撕扯出放射状水墨冲击波；满面金刚忿怒圆睁，怒吼声仿佛穿透画卷而出。

# 太虚
构图极具东方神道与道家超凡玄机的空灵意境。阴阳师身披纯白与淡藤紫交织的宽大狩衣，头戴挺拔黑色立乌帽子，迎风踏虚凌空。双目微合、神情宁静超然。双指竖立引爆一道朱砂符咒，数以百计由墨线构筑的纸鹤式神自宽袍大袖中呼啸而出，在身周盘旋形成太极阴阳般的流线墨涡与空间裂痕，澄澈空灵却蕴含无尽法力。

# 撼岳
充满战国沙场铁血肃杀之气的重甲将领像。通体赤红漆配玄黑铸铁的当世具足大铠重逾百斤，肩披厚重大袖，头戴金色巨大弯月前立的鬼角武将兜盔。面部戴着獠牙怒张的铁面颊（面破），仅从眼缝中透出宛如恶狼般的冰冷杀气。大将弓步沉身，双手拖拽着一柄长达两米开外的巨大野太刀（大太刀），刀刃与沙场岩石摩擦迸射出炽烈火星，在地面犁出深黑的墨迹沟壑。背后的血红战旗在硝烟狂风中猎猎作响，扑面而来的是摧枯拉朽的战场压迫感。

# 听风
极具日式禅意与“居合瞬杀”张力的盲剑客意象。漫天风雨如墨线穿林打叶，一位身着粗粝麻布僧衣、肩披破损防雨蓑衣的行脚瞽者静立于暴风雨的核心。粗布缠目，神情如止水般波澜不惊，微微侧头迎着雨声与风息。他双手正捧着一柄斑驳古旧的竹制尺八凑在唇边吹奏，然而尺八的底端却悄无声息地半滑出一截薄如蝉翼的寒光细刃。无形的音律与凌厉的剑气化作一道道环形扩散的水墨声波震荡波纹，将倾盆大雨在周身数尺之外尽数切碎弹开，大音希声，剑未全出而杀意已遍布天地。

# 红莲
展现神道诛魔巫女决绝悲壮的破空射日之势。纯白振袖与深红绯袴在暴风中凌空翻涌，乌黑长发束以绯红发带飞扬散开，在身后炸成巨幅水墨雷云与金红流火的枫叶风暴。巫女反向凌空倒挂，双手将一张巨大不对称朱黑和弓挽如满月，箭尖凝聚的纯阳真火映照着冷冽坚毅的凤眸，气贯长虹，箭出如流星破晓。

# 幽蝶
极致张力的夜行忍者反重力瞬杀意象。身着深紫与纯黑紧身夜行衣的冷酷女忍自半空倒挂倒悬飞跃，双臂甩出沉重精钢锁镰；高速旋转的飞镰与层层金属锁链在半空绞杀出巨大的黑色水墨同心圆风暴，墨滴与飞针如暴雨倾泻。黑色面纱后一双琥珀金瞳在杀戮漩涡中死寂冷冽，轻灵诡谲如幽冥飞蝶。

# 裂空
沧桑浪人于万顷波涛间拔刀破浪的惊天绝技。破损墨蓝羽织翻飞，头顶竹笠被狂风掀向身后，露出刀削般的面庞与桀骜嗜战的眼眸。浪人以极低的重心暴起前冲，居合出鞘瞬间，弧形银刃劈出一道横贯画幅的半月白炼与飞溅的泼墨巨浪，北斋《神奈川冲浪里》般的墨色浪头在周身崩裂，刀意裂空，快如奔雷。

# 龙啸
皇家战姬统帅千军的破阵贯云之威。身披雪亮银白龙鳞轻铠，内衬孔雀蓝与明黄缎带，长及腰际的墨色高马尾与雪白战袍披风迎风狂舞，在身后卷起腾空欲飞的狂暴墨龙气旋。女将踏空突刺，双手合握丈二亮银大枪斜贯对角，银色枪尖与炽红枪缨撕裂长空，英姿勃发，威仪傲睨天下。

# 业火
战国暴走猎魔狂客的浴火逆战奇观。身披赤红与碳黑相间的破损阵羽织，狂客自半空翻身腾跃，双手倒持沉重青铜火绳短铳斜向对角暴射！铳口喷薄出浓烈的水墨硝烟与硫磺火星，在身后聚拢成遮天蔽日的黑色墨烟云团。狂放不羁的面庞带着狰狞大笑，金赤异瞳穿透火雾，尽显焚尽世间诸恶的癫狂野性。

# 影刃
疾风掠境的双刀女武士绝杀之姿。双刃交叉切出破空黑墨轨迹，飞扬如浪涛的泼墨黑发与青蓝羽织交相辉映，神情冷峻坚毅。

# 月华
单手反执长薙刀凌空斜跃的名门战姬。巨幅青绿战袍与黑发如瀑布倒倾，薙刀划破长空留下一道优美弧光，气场清冷高贵。
