# 萌图画廊 (Gallery) 🎨

一个轻量、现代且优雅的图片展览网站。采用自适应无缝多列瀑布流（Masonry Grid）布局，支持系列图集预览、沉浸式全屏画廊浏览与秒级即时检索。

## ✨ 特性一览

- 🌸 **萌系现代 UI**：参考经典画廊排版，配备粉红渐变品牌标识、大圆角卡片（20px）、柔和立体阴影与丝滑悬停浮起动画。
- 📁 **文件夹即系列**：无需复杂数据库，以 `photoes/` 目录下的每个子文件夹作为一个独立图集系列，自动提取第一张作为封面，右上角智能统计张数徽章（例如 `3P`）。
- ⚡ **高性能首屏加载**：内置基于 Pillow 的 WebP 缩略图生成与内存/磁盘双重缓存机制，海量超清大图也能毫秒级秒开。
- 🔍 **秒级即时搜索**：顶部工具栏支持按系列文件夹名称即时拼音/文本模糊过滤，带一键清空与全局快捷键（`/` 或 `Ctrl+K`）。
- 🖼️ **沉浸式画廊全屏浏览 (Lightbox)**：点击任意系列卡片即可进入专属全屏看图模式，支持缩略图导航条、上一张/下一张切换、滚轮放大缩小、原图高清下载。
- 🚀 **极简启动**：Windows 下双击 `start.bat` 即可自动寻找空闲端口并拉起浏览器。

---

## 🛠️ 技术栈

- **后端**：Python 3 + FastAPI + Uvicorn + Pillow
- **前端**：原生现代 JavaScript (ES6+) + CSS 自适应高度平衡 Masonry 瀑布流算法（零打包、开箱即用）

## 🚀 快速开始

### 方式一：Windows 一键启动（推荐）

直接双击运行项目根目录下的 **`start.bat`** 即可。

### 方式二：命令行启动

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   python server.py
   ```

3. 访问浏览器：
   打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)（若 8000 端口占用将自动顺延）。
